文档结构

这份手册每一章讲什么，以及文中几张结构示意图的位置。

 一、背景

docorder 要解决的问题，一个两步作业的最小例子，docorder 在设计上做了哪些取舍，以及当前版本有哪些能力边界。

 二、核心概念与术语

实体、上游快照、算子与算子 home、function、作业与节点、epoch 与 stage、runner 与应得名单，每个概念都说明它是什么、由谁创建、保存在哪里。

 三、工作流程

一次运行从检查作业图开始，到逐个节点执行结束，中间每一步做了什么；还包括并行执行、失败重试、source 节点的特殊处理，以及再次运行时 docorder 如何决定每个结果的去留。

 四、指纹与哈希

docorder 里的三种哈希各算什么，怎么用 `fingerprint` 声明对外部文件的依赖，`record` 与 `depend` 的分工，路径模板怎么写，以及怎么排查一个每次运行都重做的实体。

 五、使用场景

几种典型的作业图分别适合什么任务，以及哪些任务不适合用 docorder。

 六、配置

docorder 如何找到算子、`props.json` 里每个键的含义、作业和节点的参数、运行函数 `execute` 的参数、转换代码和模板分别读到哪些配置，以及相关的环境变量。

 七、算子分类与内置 function

五种算子的区别，每种算子可以搭配哪些 docorder 自带的转换类，每个转换类有哪些配置项、产生什么结果、在什么情况下失败。

 八、渲染类 function 与模板变量

模板里可以直接使用的全部变量，以及在内置变量不够用时，六种增加模板变量的方法。

 九、开发自己的 function

应该继承哪个基类、需要实现哪些方法、在方法里可以使用哪些对象、必须遵守哪些约定、代码文件放在哪里，以及如何为它编写测试。

 十、在自己的项目中使用 docorder

从安装、规划目录、准备输入数据、编写算子、编写启动脚本，到运行、查看结果和修改后再次运行的完整步骤。

 十一、数据治理案例

`examples/data-governance/` 下的真实作业，从 dbt 模型的指标清单到词根表、归属表和成员表，四个作业怎么接力。

 十二、最佳实践

把 docorder 用稳的几条约定，覆盖目录与命名、增量与幂等、算子 home 的组织、错误处理、大模型调用成本、失败恢复和常见反模式。
