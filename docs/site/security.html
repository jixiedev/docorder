安全

English

这个项目会在本机启动进程。JsonnetToPrompt 调用 jsonnet 编译上游正文；Command 执行作业配置里的 argv；PromptToLLM 执行工具定义里的 run，并把上游正文交给它。这些进程以运行作业的用户身份执行，能读写该用户能访问的文件。只对你信任的目录和配置运行作业。

Command 不经过 shell，但 argv 里的 {键} 会换成渲染环境里的值，例如 {entity.source_data}；上游的附加信息和正文分别用 entity.source_tag 和 entity.source_data 引用。argv 写成 sh -c 之类的形式时，这些值会被当作 shell 代码执行。

PromptToLLM 不内置任何工具，包里也不附带预设。工具来自节点参数 tool、home 里的 tools/<名字>.json，或环境变量 DOCORDER_LLM 指向的 JSON 文件；进程参数完全以那份定义为准。若定义里给模型工具开了跳过确认、关闭沙箱之类的选项，工具就能不经确认修改 workspace 里的文件。workspace 应是你打算让这个工具修改的那份目录树，不要指向含有密钥或其他敏感文件的目录。

发现漏洞时不要开公开 issue。私下联系维护者，说明影响和复现方式。在维护者确认之前，不要附上可以用来攻击他人环境的利用步骤。
