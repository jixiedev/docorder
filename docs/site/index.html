Docorder / 文档 / 概览

Python 库 · stage runner

按阶段处理一批结构相同的目录

许多相似的对象收成目录，再沿一张有向无环图逐段转换。算子只描述转换。输出放在哪一次运行里，由这次运行决定。

什么是 docorder

进度记在每个对象自己的目录里。一段等上一段结束，段内只补没做完的、重做上游变了的。

1 一批相同的对象

一张张表、一个个模型，走相同的几步：取得源文件，渲染提示词，调用模型，留下结果。

2 调用慢，而且会停在半路

令牌用尽、进程退出、外部命令返回错误，都可能发生在几千个对象已经处理了一部分之后。

3 算子可以换一次运行再用来

算子描述转换，不描述这次的输出位置。输出目录和要覆盖的参数，在组装作业时再填上。

核心概念

第一次接触 docorder，先熟悉这几个概念：

  • 实体一个目录装着正文和附加信息，是处理的最小单位。
  • 上游快照记下这个结果是根据哪份上游算出来的，用来判断要不要重做。
  • 算子与算子 home描述「这一步怎么做」，与某一次运行无关，可以反复使用。
  • epoch 与 stage一批结果的名字，以及一段处理的单位。
  • runner 与应得名单算出这一步应该有哪些结果，再和磁盘上的逐一比较。

完整的定义见 核心概念与术语一章，术语速查见 术语表。

模型

实体是一层子目录，算子有五种类型，作业是一张图。三者的界线决定了一次运行怎么落盘、怎么续跑。

实体是一层子目录

目录名就是实体名。名字不能含斜杠，也不能以 . 或 _ 开头。data 是正文，tag.json 是给下游过滤和填模板的特性，有上游时还含 upstream 快照。图的起点没有上游，因此不写这个键。

20261015 是这次运行的 epoch，也就是实体所在的那层子目录名。换一个 epoch 等于换一个子目录，上一次的结果留在原处。

runs/
├─ tables/                 source
│  └─ 20261015/orders/
│     ├─ data             正文
│     └─ tag.json         特性
└─ prompt/                 map
   └─ 20261015/orders/
      ├─ data
      └─ tag.json         含 upstream

算子有五种类型

算子的静态文件放在 home 里，由 DOCORDER_HOMES 搜索，靠前的同名目录优先。props.json 里的 type 和 class 必须书写，作业不能改；class 写成 模块:类名，或写成 primary:类名 以加载 home 里的 primary.py。

作业是一张图

每个节点有名称、算子 home、本次输出路径。输出路径不写进 home。除 source 以外，每个节点声明一个上游。runner 按拓扑顺序执行，一个节点全部结束才开始下游。书写顺序用来排定互不依赖的节点谁先谁后。

tables → prompt → answers → index

快速开始

先装上，跑通一个两步作业，再逐步展开。

  • 安装与快速开始用 uv 从仓库装上，写一个两步作业跑通。
  • 完整项目示例从规划目录到看结果，每一步都有可运行的文件。
  • 配置props.json 的每个键、节点参数、环境变量。

git clone https://github.com/jixie-wish/docorder.git && cd docorder && uv sync

Python 3.10 或更高版本 Jinja2、PyYAML、tqdm 随安装装上 算子 home 由你放到 DOCORDER_HOMES 里 JsonnetToPrompt 需要本机 jsonnet docorder status 查看输出目录里的 epoch
runs/tables/20261015/… runs/prompt/20261015/…

directory 的相对路径相对算子 home 解析。每个直接子目录只要含有 data 和 tag.json 就成为一个实体，目录名就是实体名，正文是 data 的原文。source 只在 start_from_scratch=True 时按目录重写；否则下游读取输出路径上已经存在的实体。config 可以覆盖 home 里的同名 function 参数。parallelism 大于 1 时 runner 在当前进程里用线程分片，不另起子进程。

再跑

runner 把应得名单和磁盘上的目录做比较。模型调用按 home 里的 retry 在本段内重试；重试耗尽后，已写好快照的实体留下，下次从其余实体继续。

orders
  • data
  • tag.json
  • upstream 仍吻合
留下

快照里的上游哈希和 epoch 都与当前一致。

items
  • data
  • tag.json
  • 没有快照，或哈希变了
执行并覆盖

draft
  • data
  • tag.json
  • 名单里已经没有
删除

目录里还在，应得名单里已经没有这个名字。
